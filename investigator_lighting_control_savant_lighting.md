### Strengths
- **TrueImage display technology**: Genuinely innovative feature showing actual scene images on switch faces, creating superior visual interface compared to traditional keypads
- **Best-in-class user experience**: Professional integrators consistently rate Savant's unified interface and mobile app as superior for controlling all home systems from one intuitive platform
- **Native Lutron integration**: Direct compatibility with both HomeWorks and RadioRA 3 systems allows leveraging Lutron's proven lighting hardware while maintaining Savant's superior interface

### Deficiencies
- **Market reveals hardware limitations**: Professional integrators frequently default to Lutron dimmers when specifying Savant systems, indicating less comprehensive LED compatibility and less precise dimming performance
- **Shorter warranty period**: 3-year standard warranty versus Lutron's 8-year coverage suggests lower manufacturer confidence in hardware longevity
- **Newer market presence**: Less field data available for Savant's own lighting products compared to established competitors

### What You Should Know
Savant excels as an automation platform with the best user interface in the industry, but its lighting hardware is still developing. The market itself tells the story — many luxury installations use Savant for the brain and interface while relying on Lutron for the actual lighting control. If you want the best of both worlds, this hybrid approach works well but requires professional integration. Savant's TrueImage displays are genuinely innovative, showing actual room scenes on the switch face rather than generic icons.

### System Architecture Note
Savant uses Bluetooth mesh communication for its lighting devices, operating on the crowded 2.4 GHz spectrum. While this enables easier setup, it's potentially less reliable than Lutron's dedicated Clear Connect frequency. Apple TV can serve as the Savant Host, creating an elegant but Apple-dependent ecosystem.
